# Landing Page Specification

## Overview
Build a modern, conversion-optimized landing page for a SaaS product called "TaskFlow" - a project management tool for remote teams.

## Target Audience
- Remote team leaders
- Project managers
- Startup founders
- Engineering managers

## Core Value Proposition
TaskFlow helps remote teams stay aligned with real-time collaboration, automated workflows, and intelligent task prioritization.

## Required Sections

### 1. Hero Section
- Headline: "Project Management That Actually Works for Remote Teams"
- Subheading: "Stop juggling tools. Start shipping faster with TaskFlow's intelligent workspace."
- Primary CTA: "Start Free Trial"
- Secondary CTA: "Watch Demo"
- Hero image/illustration showing dashboard UI

### 2. Social Proof Banner
- Trust indicators: "Trusted by 10,000+ teams"
- Logo carousel of fake companies (TechCorp, StartupCo, etc.)

### 3. Features Section
Three-column grid with:
- **Real-Time Collaboration**: See what your team is working on, instantly
- **Smart Automation**: Workflows that adapt to how you work
- **Intelligent Prioritization**: AI-powered task ranking

### 4. Product Showcase
- Large screenshot or demo of the product
- 3-4 callout annotations highlighting key features
- "See it in action" CTA

### 5. Benefits Section
- "Ship 2x Faster": With automated workflows
- "Reduce Meeting Time by 50%": Async-first design
- "Never Miss a Deadline": Smart notifications

### 6. Pricing Section
Three tiers:
- **Starter**: Free - For small teams
- **Pro**: $12/user/month - For growing teams (POPULAR badge)
- **Enterprise**: Custom - For large organizations

### 7. Testimonials
3 customer testimonials with:
- Quote
- Name, role, company
- Avatar image (placeholder)

### 8. Final CTA
- Strong headline: "Ready to Transform Your Team's Workflow?"
- CTA button: "Start Your Free Trial"
- No credit card required message

### 9. Footer
- Product links
- Company links
- Social media icons
- Copyright notice

## Technical Requirements
- Responsive design (mobile, tablet, desktop)
- Modern, clean aesthetic
- Smooth scrolling and animations
- Fast load time
- Accessible (WCAG 2.1 AA)

## Tech Stack
- HTML5, CSS3, vanilla JavaScript
- Or modern framework (React, Vue, Svelte)
- Tailwind CSS for styling
- Smooth scroll library
- No backend required (static site)

## Design Principles
- Clean, professional look
- High contrast for readability
- Generous whitespace
- Clear visual hierarchy
- Mobile-first approach
