# Lessons Learned

## Initial Setup
- Start with mobile-first design approach
- Use semantic HTML for better SEO and accessibility

## Performance
- Lazy load images below the fold
- Inline critical CSS for faster initial render
- Use modern image formats (WebP with fallbacks)

## Design
- Maintain consistent spacing scale (4px, 8px, 16px, 24px, 32px, 48px, 64px)
- Limit color palette to 2-3 primary colors plus grays
- Use proper contrast ratios for text (4.5:1 minimum)

## Development
- Test on actual devices, not just browser DevTools
- Keep CSS organized (components, utilities, layout)
- Use CSS variables for theming and consistency
